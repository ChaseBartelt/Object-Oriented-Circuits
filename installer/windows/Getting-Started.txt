OBJECT-ORIENTED CIRCUITS

1. Open VS Code and create a folder for your circuits.
2. Save a file with the .ckt extension. Its language mode should be Object-Oriented Circuits.
3. Try this circuit:

V1(12) between(supply, 0);
R1(2k) between(supply, out);
R2(1k) between(out, 0);

4. Click the play button at the top right of the editor. Node out should be 4 V.
5. Save source to refresh the same viewer. Save layout in the viewer to keep drawing edits.

Python, the compiler, viewer, mathematical dependencies and chip library are included.
You do not need Git or the source repository. Your existing Python installations are unchanged.
Keep your .ckt files and .ckt.layout.json files together in your own project folders.

Use OOC: Check for Updates from the VS Code command palette. Installed application updates
are offered from published GitHub releases. Close the old viewer after an update before Run.
Some extension registration changes require a VS Code reload; compatible feature updates
can be applied live. No editor restart is forced.

If VS Code was not found, install it from https://code.visualstudio.com/download and rerun
OOC Setup. You can also install the bundled extension VSIX through Extensions > Install from VSIX.
The OOC viewer is available from the Windows Start menu without VS Code.

OOC normally installs in %LOCALAPPDATA%\Programs\OOC. Its versioned runtime can run the
compiler from a terminal: runtime\python.exe -m circuitlab.tooling.cli solve your-file.ckt
The active runtime path is recorded in install.json. The extension detects it automatically.

Uninstall through Windows Installed apps. Circuit source, saved circuit layouts and shared
gate layout preferences are retained. VS Code manages its extension separately; remove it
from the Extensions view if you no longer want language support.

Project and documentation: https://github.com/EchoingFarts/Object-Oriented-Circuits
