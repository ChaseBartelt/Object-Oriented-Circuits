Windows x64 installer for Object-Oriented Circuits.

- Includes private Python, compiler, viewer, numerical dependencies and the complete chip library.
- Installs the OOC extension into an existing VS Code installation; no source checkout is required.
- Detects the installed runtime and chip library automatically.
- Offers complete application updates from published GitHub releases.
- Preserves circuit source, layout sidecars and gate layout preferences.
- Uses the organized Python modules directly; redundant root forwarding files have been removed. Existing circuit syntax is unchanged.

Install VS Code separately if you want IDE editing. Setup can install the viewer without it; rerun Setup after installing VS Code to add the extension. Windows 10 (1809+) or Windows 11, x64.

This build is unsigned. Windows may show an unknown-publisher notice. Native chip models retain their documented approximations and unsupported modes.
